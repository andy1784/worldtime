# Чеклист подключения поисковых систем

## ✅ Google Search Console — ВЕРИФИЦИРОВАНО
- Мета-тег добавлен на все 692 страницы
- Sitemap доступен по адресу: https://worldtimessync.com/sitemap.xml

### Осталось сделать вручную:
1. Зайти на https://search.google.com/search-console
2. Свойство уже добавлено и верифицировано
3. Перейти в раздел **Sitemaps**
4. Добавить: `sitemap.xml`
5. Нажать **Submit**

## 🔲 Google PageSpeed Insights — ПРОВЕРКА
Без API ключа автоматическая проверка невозможна.

### Сделать вручную:
1. Зайти на https://pagespeed.web.dev/
2. Ввести: `https://worldtimessync.com`
3. Нажать **Analyze**
4. Сохранить результаты (Mobile + Desktop)

---

## 🔲 Bing Webmaster Tools — ПОДКЛЮЧЕНИЕ
Требует аккаунт Microsoft.

### Сделать вручную:
1. Зайти на https://www.bing.com/webmasters
2. Войти с аккаунтом Microsoft (или создать)
3. Нажать **Add Site**
4. Ввести: `https://worldtimessync.com`
5. Выбрать метод верификации: **HTML Meta Tag**
6. Скопировать код верификации Bing
7. Отправить код мне — я добавлю на все страницы
8. После верификации добавить sitemap: `https://worldtimessync.com/sitemap.xml`

---
