React / Next.js

// JSX
import { useEffect } from 'react';

export function WorldClock() {
    useEffect(() => {
        const script = document.createElement('script');
        script.async = true;
        script.src = 'https://worldtimessync.com/embed.js';
        document.head.appendChild(script);
        
        script.onload = () => {
            window.WorldTimeSync.init({
                container: '#wts-clock',
                cities: ['new-york', 'london', 'tokyo']
            });
        };
        
        return () => window.WorldTimeSync?.destroy();
    }, []);
    
    return 
;
}

Frequently Asked Questions

How do I embed the world clock on my website?

Choose either the iframe method (simplest, works everywhere) or the JavaScript method (async, auto-resize, dynamic API). Copy the code snippet from above and paste it where you want the clock to appear.

Does it work with WordPress?

Yes! For WordPress, use the Custom HTML block (Gutenberg) or a Text widget. Paste the iframe code directly. For the JavaScript version, add the script tag to your theme's footer.php or use a plugin like "Header and Footer Scripts".

Can I customize which cities are shown?

Yes — both methods support custom city lists. Choose from 70+ major cities worldwide (see the full list above). The JavaScript version accepts an array of city slugs; the iframe version uses a comma-separated cities URL parameter.

Is the widget free to use?

Yes, completely free for personal and commercial use. We only require the attribution link (included in all embed codes) to remain visible. No registration, no API key, no rate limits, no tracking.

Does it work on mobile devices?

Yes, fully responsive. The widget adapts to any container width. The JavaScript version auto-resizes height via postMessage. The iframe version works best with a fixed height or CSS aspect-ratio.

How does it handle daylight saving time?

Automatically. The widget uses the IANA time zone database which includes all current and historical DST rules. Times update in real-time and DST transitions are handled correctly.

Can I use my own timezone (not in the city list)?

Yes — pass any valid IANA timezone identifier (e.g., America/Anchorage, Pacific/Honolulu) instead of a city slug. Both iframe URL parameters and JavaScript API accept raw timezone strings.

Does the widget set cookies or track users?

No. The widget loads from our CDN but sets no cookies, uses no localStorage, and performs no analytics or fingerprinting. The only network request is for the widget HTML/JS itself.

What browsers are supported?

All modern browsers: Chrome, Firefox, Safari, Edge (last 2 versions). IE11 not supported. The widget uses standard web APIs (Intl.DateTimeFormat, postMessage, fetch).
