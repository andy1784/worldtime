If you run a WordPress site and your audience is international, adding a world clock widget is one of the most useful things you can do. Visitors can instantly see the current time in their city — no mental math required.

Our Free WordPress Plugin

We built a free WordPress plugin that adds a customizable world clock to your site. It's lightweight, mobile-responsive, and doesn't slow down your page.

Features:

  • Display current time in any city
  • Add multiple clocks for different time zones
  • Customizable appearance (colors, size, format)
  • Automatic DST handling
  • No external dependencies — works offline after initial load

Installation

  1. Download the plugin from our WordPress plugin page
  2. Go to your WordPress admin → Plugins → Add New → Upload Plugin
  3. Upload the .zip file and activate
  4. Add the widget to your sidebar or use the shortcode [worldtime city="New York"]

Shortcode Examples

  • [worldtime city="New York"] — Single clock for New York
  • [worldtime city="London" format="24"] — 24-hour format
  • [worldtime city="Tokyo" label="Tokyo Office"] — Custom label
  • [worldtime cities="New York,London,Tokyo"] — Multiple clocks

Alternative: Embed Our Widget

If you don't want to install a plugin, you can embed our widget directly using an iframe. See our embed guide for the code.

Why Add a World Clock?

If your site has any international audience — customers, readers, community members — a world clock is genuinely useful. It helps visitors:

  • Know when your support team is available
  • Convert time zones for scheduled events
  • Feel like your site is built for a global audience

It's a small addition that makes a big difference for international visitors.
